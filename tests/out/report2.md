- Opened 12 new regional offices.

- Launched the mobile rewards app.

### Priorities for next year

1. Expand into two new markets.
2. Reduce churn below 5%.
3. Ship the partner API.

## Integration Example

Merchants can award points with a single API call:

```
import requests
def award(customer_id, points):
    return requests.post("/v1/points",
        json={"customer": customer_id, "points": points})
```
